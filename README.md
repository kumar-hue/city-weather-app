# city-weather-app

A simple web-based weather application that allows users to search for weather information by city name using the OpenWeatherMap API.

## Features

- Search weather details by city name
- Displays real-time weather information
- Shows temperature
- Shows humidity
- Shows wind speed
- Shows atmospheric pressure
- Displays weather description
- Dynamic weather icons based on weather conditions
- Clean and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## How It Works

1. Enter a city name in the search field.
2. The application sends a request to the OpenWeatherMap API.
3. The API returns the current weather data for the requested city.
4. JavaScript processes the API response.
5. The weather information and corresponding weather icon are displayed on the page.
